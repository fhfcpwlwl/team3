# Command Note

프로젝트 진행 중 자주 사용하는 필수 Git 명령어와 그 의미를 정리한 노트입니다.

---

## 1. 저장소 시작 및 가져오기

| 명령어 | 의미 |
| :--- | :--- |
| `git init` | 현재 디렉토리를 로컬 Git 저장소로 초기화 |
| `git clone <저장소-URL>` | 원격 저장소의 전체 내용을 로컬로 복제 |
| `git clone -b <브랜치명> --single-branch <저장소-URL>` | 특정 브랜치 하나만 지정하여 복제 |

---

## 2. 변경사항 저장 및 기록 (기본 워크플로우)

| 명령어 | 의미 |
| :--- | :--- |
| `git status` | 현재 작업 디렉토리의 상태 확인 (추적되지 않은 파일, 수정된 파일 등) |
| `git add <파일명>` | 특정 변경 파일을 스테이징 영역(Staging Area)에 추가 |
| `git add .` | 변경된 모든 파일을 스테이징 영역에 추가 |
| `git commit -m "메시지"` | 스테이징 영역의 변경사항을 로컬 저장소에 기록 (버전 생성) |
| `git commit --amend` | 직전에 작성한 커밋 메시지 수정 또는 누락된 파일 추가 |

---

## 3. 브랜치(Branch) 관리

| 명령어 | 의미 |
| :--- | :--- |
| `git branch` | 로컬 브랜치 목록 확인 (`*` 표시가 현재 브랜치) |
| `git branch -a` | 로컬 및 원격(Remote)의 모든 브랜치 목록 확인 |
| `git branch <새-브랜치명>` | 새로운 브랜치 생성 |
| `git switch <브랜치명>` <br> `git checkout <브랜치명>` | 지정한 브랜치로 이동 |
| `git switch -c <새-브랜치명>` <br> `git checkout -b <새-브랜치명>` | 새로운 브랜치를 생성하고 동시에 그 브랜치로 이동 |
| `git merge <가져올-브랜치명>` | 현재 브랜치에 다른 브랜치의 변경사항을 병합 |
| `git branch -d <브랜치명>` | 작업이 끝난 로컬 브랜치 삭제 |

---

## 4. 원격 저장소(Remote) 동기화

| 명령어 | 의미 |
| :--- | :--- |
| `git remote add origin <저장소-URL>` | 원격 저장소 주소를 `origin`이라는 이름으로 등록 |
| `git remote -v` | 연결된 원격 저장소의 주소 확인 |
| `git fetch` | 원격 저장소의 최신 이력을 로컬로 가져옴 (병합은 하지 않음) |
| `git pull origin <브랜치명>` | 원격 저장소의 최신 변경사항을 가져와 현재 브랜치와 병합 (`fetch` + `merge`) |
| `git push origin <브랜치명>` | 로컬 저장소의 커밋 이력을 원격 저장소에 업로드 |

---

## 5. 이력 확인 및 되돌리기 (유지보수)

| 명령어 | 의미 |
| :--- | :--- |
| `git log` | 커밋 히스토리(로그) 확인 |
| `git log --oneline` | 커밋 히스토리를 한 줄로 간결하게 확인 |
| `git diff` | 스테이징 전, 작업 디렉토리와 이전 커밋의 소스코드 차이점 비교 |
| `git restore <파일명>` | 워킹 디렉토리의 변경사항을 취소하고 최근 커밋 상태로 되돌림 |
| `git reset --hard <커밋-해시>` | 지정한 커밋 시점으로 완전히 되돌림 (이후 커밋과 작업 내용 삭제 주의) |
| `git revert <커밋-해시>` | 기존 커밋의 변경사항을 취소하는 '새로운 커밋'을 생성 (협업 시 안전한 되돌리기) |
| `git stash` | 현재 작업 중인 변경사항을 임시 공간에 저장하고 워킹 디렉토리를 깨끗하게 만듦 |
| `git stash pop` | 임시 저장했던 변경사항을 다시 불러와 적용 |
